# 运输回单结算台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

由车辆调度原型改造的运输回单结算台，数据默认保存在浏览器 localStorage（键：`dfwlfront-3-settlement`），刷新后结算单、票据与修订链全部保留。

## 结算规则

- 每单记录实际里程（起始/结束表显）、油耗、路桥费、其他费用与应收。
- 提交即校验，任一冲突都会阻止提交并逐项列出：
  - **里程倒挂**：结束表显小于起始表显；
  - **重复报销**：同一任务同一费用项（油费/路桥费/其他）只允许一张票据，单内与跨单都核对；
  - **票号重复**：票号全局唯一；
  - **票据与明细不一致**：按费用项双向核对票据合计与费用明细。
- **结算确认**后费用快照冻结为 R1，不可改单、不可删除；确认时会按最新数据复检冲突。
- **补录票据**只能生成新修订（R2、R3…），原修订原值保留，修订链可展开核对；补录同样受重复报销与票号唯一约束。
- 补录造成的票据合计与费用明细差额会标记为“挂账”，在卡片与修订链中可见。

核心校验逻辑在 `src/settlement.ts`，为纯函数，便于测试与核对。
